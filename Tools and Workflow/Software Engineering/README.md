# Software Engineering

Writing code that works, keeps working, and that other people can read.

## Shortcuts
In VS Code (with the `School` folder open), type a word and press **Tab**. Press **Tab** again to jump to the next blank. If nothing happens, press **Ctrl+Space** and pick it.

| Type | In a... | You get |
|---|---|---|
| `pytest` | `.py` | A test (run with `python -m pytest`) |
| `cppheader` | `.h` | A header file with `#pragma once` |
| `cppclass` | `.cpp` / `.h` | A class with a constructor |
| `pyclass` | `.py` | A Python class |
| `note` | `.md` | A topic note |
| `bug` | `.md` | Record an error, its cause, and the fix |
| `project` | `.md` | A project README |

Full list: the main `README.md` at the top of the `School` folder.

## Topic checklist
- [ ] Debugging: reading errors and using a debugger (gdb, VS Code)

- [ ] Testing: unit tests (pytest, GoogleTest)
- [ ] OOP design principles (SOLID)
- [ ] Common design patterns
- [ ] Build systems (CMake) and package managers
- [ ] Code review and teamwork with Git
- [ ] Planning a project: requirements, tasks, and Agile basics
