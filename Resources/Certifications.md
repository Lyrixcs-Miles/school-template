# Certifications

Certifications are optional. They prove to employers what you know, which helps most
for IT, networking, security, and cloud jobs. For developer jobs, projects on GitHub
usually matter more.

You learn the material in the subject folders; this page shows which folder covers each one.
Tick a certification once you've passed it.

## Common paths
- **IT support → security:** A+ → Network+ → Security+ → CySA+ or PenTest+
- **Cloud:** AWS Cloud Practitioner or AZ-900 → an associate-level cloud certification
- **Networking:** Network+ → CCNA

## Free first, pay later
Paid exams (CompTIA, Cisco, AWS, ...) cost real money, so:
1. **Learn the material for free** in the subject folders. Use Professor Messer, Microsoft Learn, and AWS Skill Builder.
2. **Earn free certificates first** to show progress: CS50, freeCodeCamp, and Google IT Support (with Coursera financial aid).
3. **Only pay for an exam once your practice tests score well**, so you pass the first time.
4. **Look for discounts:** CompTIA has student pricing, and vendors often run free exam vouchers in challenges or events.
5. **Build projects alongside:** a GitHub portfolio is free and counts as proof of your skills.

## Tips
- Every exam publishes free **exam objectives** that list what can be tested. Save them in that subject's `Resources` folder.
- Free study material: Professor Messer (CompTIA), AWS Skill Builder, and Microsoft Learn.
- Check the official site for current exam versions and prices before you book.
