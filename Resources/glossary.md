# Glossary

Every new term, explained in my own words. Keep it in A–Z order. Type `term` + Tab to add a row.
If you can't explain it simply, you don't understand it yet, so look it up again.

| Term | Meaning (in my words) | Subject |
|---|---|---|
| Algorithm | A step-by-step set of instructions to solve a problem | DSA |
| API | A way for one program to talk to another, like a menu of requests you can make | Web |
| Bug | A mistake in code that makes it behave wrongly | General |
| Compiler | A program that turns source code (like C++) into a program the computer can run | C++ |
| DNS | The internet's phone book: turns names like google.com into IP addresses | Networks |
| IP address | A device's address on a network | Networks |
| RAM | Fast, temporary memory a computer uses while it's running | IT Fundamentals |
| Variable | A named box that stores a value | General |
