# VS Code Shortcuts

| Shortcut | What it does |
|---|---|
| Ctrl+Shift+B | Build and run the current C++ file |
| F5 | Debug the current C++ file (stops at breakpoints) |
| F9 | Set or remove a breakpoint on the current line |
| Ctrl+` | Show or hide the terminal |
| Ctrl+P | Open a file by name |
| Ctrl+Shift+P | Command palette (search any command) |
| Ctrl+/ | Comment or uncomment a line |
| Alt+Up/Down | Move a line up or down |
| Shift+Alt+Down | Copy a line down |
| Ctrl+D | Select the next match (edit several at once) |
| F2 | Rename a variable everywhere |
| F12 | Go to definition |
| Shift+Alt+F | Format the file |
| Ctrl+Shift+V | Preview a Markdown (.md) file |
