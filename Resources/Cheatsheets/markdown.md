# Markdown Cheat Sheet (for notes)

```
# Heading 1    ## Heading 2    ### Heading 3
**bold**   *italic*   `inline code`
- bullet point
1. numbered item
- [ ] checkbox      - [x] ticked
[link text](https://example.com)
![image](picture.png)
> quote
---            (horizontal line)
```

Code blocks: put three backticks, then the language name, on the line above the code. Put three backticks on the line below it.

Preview in VS Code: **Ctrl+Shift+V**
