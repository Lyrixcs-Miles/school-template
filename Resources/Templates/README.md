# Templates

Copy a template folder into the subject you're working on, then rename it.
For example, copy `C++/multi-file-project` to `Programming Languages/C++/Projects/calculator`.

| Template | Use it for |
|---|---|
| `C++/single-file` | One-file programs and exercises |
| `C++/multi-file-project` | Bigger C++ programs, with headers and CMake |
| `Python/script` | One-file Python programs |
| `Python/project` | Bigger Python programs with modules, tests, and a virtual environment |
| `Web` | A blank HTML, CSS, and JavaScript page |
| `SQL` | Creating tables, inserting data, and querying it |
| `Bash` | Shell scripts (Linux) |
| `Docker` | Running an app in a container: Dockerfile and compose.yaml (copy into a Python project) |
| `Notes/topic-note.md` | A note on one topic |
| `Notes/project-readme.md` | The README for a project |
| `Notes/ctf-writeup.md` | A writeup for a CTF challenge |

## Faster: shortcuts in VS Code
Instead of copying a template, you can often type a shortcut such as `pymain` or `cppmain` and press **Tab**.
See the **Shortcuts** section in the main `README.md` for the full list.
