# Project Ideas

Build things: it's the fastest way to learn. Put each project in the
`Projects` folder of its subject. Tick one off when it's done.

## Python
- [ ] **Beginner:** number guessing game · to-do list in the terminal · unit converter
- [ ] **Beginner:** password generator · quiz game that loads questions from a file
- [ ] **Intermediate:** expense tracker that saves to CSV and draws charts · web scraper
- [ ] **Intermediate:** a Discord or Telegram bot · a file organiser that sorts your Downloads folder
- [ ] **Advanced:** a REST API with Flask or FastAPI and a database

## C++
- [ ] **Beginner:** calculator · temperature converter · times-table printer
- [ ] **Beginner:** tic-tac-toe in the terminal
- [ ] **Intermediate:** bank account system with classes · student grade manager that saves to files
- [ ] **Intermediate:** text adventure game · Snake in the terminal
- [ ] **Advanced:** your own simple `vector` or `string` class · a game with SFML or raylib

## Other languages
Rebuilding a project you already made in Python is a great way to learn a new language.
- [ ] **C:** a calculator · your own `strlen`, `strcpy`, and a dynamic array that grows with `realloc`
- [ ] **Java:** a library or bank system with classes · a to-do app that saves to a file
- [ ] **JavaScript (Node):** a command-line to-do list that saves JSON · a quiz game in the terminal
- [ ] **C#:** a console inventory manager with LINQ · a small Unity game
- [ ] **Go:** a URL shortener web server · a tool that checks if a list of websites is up (using goroutines)
- [ ] **Rust:** a command-line word counter · a `grep` clone (the Rust Book walks you through one)

## Data Structures and Algorithms
- [ ] Build each structure yourself: linked list, stack, queue, hash map, BST
- [ ] A sorting algorithm visualiser (Python with matplotlib, or the web)
- [ ] A maze solver with BFS and DFS · a shortest-path finder on a city map (Dijkstra)

## Web Development
- [ ] **Beginner:** a personal portfolio website (use it for job applications later!)
- [ ] **Beginner:** a landing page for a made-up product
- [ ] **Intermediate:** a weather app using a free API · a to-do app that saves to localStorage
- [ ] **Advanced:** a full-stack app with a login, a database, and deployment

## Databases and SQL
- [ ] A library or school database: design the tables, then write 20 queries
- [ ] Connect your Python to-do or expense app to SQLite

## Linux and Command Line
- [ ] A backup script that zips a folder with today's date
- [ ] Finish the OverTheWire Bandit levels and write notes on each

## IT Fundamentals and Networks
- [ ] Build or take apart a PC and record each part
- [ ] A home lab in VirtualBox: Windows plus Linux on a shared virtual network
- [ ] Map your home network: devices, IPs, and what each one does
- [ ] A Python port scanner, or a simple chat app using sockets

## Cybersecurity (your own lab only)
- [ ] Set up Kali Linux plus Metasploitable, and write up how you compromised it
- [ ] Finish 10 TryHackMe rooms or PicoCTF challenges and write a writeup for each
- [ ] A Python password strength checker · a log file analyser that spots failed logins

## Cloud and DevOps
- [ ] Put one of your Python projects in a Docker container
- [ ] Add GitHub Actions to a project so tests run on every push
- [ ] Host your portfolio website for free (GitHub Pages, or AWS S3)

## AI and Machine Learning
- [ ] Analyse a dataset from Kaggle with pandas and draw charts
- [ ] Predict house prices with linear regression · classify handwritten digits
- [ ] A chatbot that uses an AI API
