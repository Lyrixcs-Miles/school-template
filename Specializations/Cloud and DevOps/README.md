# Cloud and DevOps

Run, ship, and scale software on servers and in the cloud.
**Learn after:** Linux and Command Line, Git and GitHub, Computer Networks, and one programming language.

## Shortcuts
In VS Code (with the `School` folder open), type a word and press **Tab**. Press **Tab** again to jump to the next blank. If nothing happens, press **Ctrl+Space** and pick it.

| Type | In a... | You get |
|---|---|---|
| `dockerpy` | `Dockerfile` | Run a Python app in a container |
| `bashscript` | `.sh` | A Bash script skeleton |
| `cmdtable` | `.md` | Start a table of commands |
| `cmd` | `.md` | Add a command row: command, what it does, example |
| `note` | `.md` | A topic note |
| `bug` | `.md` | Record an error, its cause, and the fix |
| `project` | `.md` | A project README |

Full list: the main `README.md` at the top of the `School` folder.

## Topic checklist
### Foundations
- [ ] What the cloud is: IaaS, PaaS, SaaS; public vs. private
- [ ] Linux servers and SSH (revisit Linux and Command Line)
- [ ] YAML and JSON config files
### Containers
- [ ] Docker: images, containers, and Dockerfile (template in Resources/Templates/Docker)
- [ ] Docker Compose: running several containers together
- [ ] Kubernetes basics: pods, deployments, and services
### Automation
- [ ] CI/CD: auto-testing and deploying with GitHub Actions
- [ ] Infrastructure as Code: Terraform basics
- [ ] Configuration management: Ansible basics
### Cloud platforms (pick one first, AWS is most common)
- [ ] AWS core: EC2, S3, IAM, VPC, RDS, Lambda
- [ ] Azure core: VMs, Storage, Entra ID, App Service
- [ ] Cost management and the free tiers
### Running things
- [ ] Monitoring and logging
- [ ] Cloud security and the shared responsibility model

## Certifications this prepares you for
- **CompTIA Cloud+**: vendor-neutral cloud
- **AWS Certified Cloud Practitioner**, then **AWS Solutions Architect – Associate**
- **Microsoft AZ-900** (Azure Fundamentals), then **AZ-104** (Azure Administrator)
- Later: **CKA** (Certified Kubernetes Administrator)
